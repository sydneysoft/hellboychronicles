## 2. Traction and measurable impact — implemented first

StoryLingo now includes first-party product instrumentation designed to create a measurable record of real usage.

### Metrics to preserve every month

Capture and export the following from the production analytics dashboard at the end of each calendar month:

- Unique visitors
- Page views
- Countries / geographic distribution
- Top routes and stories
- Referrers
- Device mix
- `story_open` events
- `language_change` events
- `practice_started` events
- `audio_started` events
- Month-over-month visitor growth
- Month-over-month story-open growth

Do not backfill or estimate historic numbers. Only use measurements captured by the production analytics system.

### Analytics event definitions

`storylingo_visit`
: A production visit with the current route and interface language.

`story_open`
: A reader opens a story, collection, chapter, comic or text edition from a tracked StoryLingo page.

`language_change`
: A reader changes the language selector.

`practice_started`
: A reader starts an instrumented vocabulary/practice interaction.

`audio_started`
: A reader starts an instrumented audio interaction.

`external_link`
: A reader follows a tracked StoryLingo / OrangeSoft external destination.

## 1. StoryLingo innovation record

### Product purpose

StoryLingo is a multilingual reading and language-learning product built around the idea that learners should stay inside a story while moving between reading, language comparison and practice rather than leaving the reading experience for a separate lesson flow.

### Current product characteristics

- A multilingual story library with language-learning support.
- Shared-language editions in which the same narrative can be read across multiple languages.
- Illustrated and text editions for different reading modes.
- Folk-tale collections across several language traditions plus original StoryLingo material.
- Vocabulary/practice, pronunciation/audio and reader-support surfaces where available in the relevant edition.
- A static-first web architecture deployed on Vercel, with lightweight serverless endpoints for security-related functions.
- First-party engagement instrumentation designed to measure reading and language-learning behaviour without storing the text a learner reads or types as analytics metadata.

### Technical differentiation to document

The strongest evidence should show the system, not merely describe it. Preserve source-code and screenshots demonstrating:

1. **Story-aligned multilingual reading** — the same narrative represented in multiple language editions so a learner can revisit equivalent scenes and phrases.
2. **Reading-first learning UX** — language support is attached to the act of reading rather than presented only as isolated lessons.
3. **Multiple presentation modes** — illustrated/graphic and text reading experiences coexist inside one content system.
4. **Cross-cultural content architecture** — Ukrainian, Polish, French, German, Russian and shared-language collections can be represented under one library model as the catalogue expands.
5. **Product analytics tied to learning actions** — StoryLingo records aggregate story openings, language changes, practice starts and audio starts so product development can be supported by measurable user behaviour.
